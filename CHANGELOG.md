# Changelog

## 0.1.0 — Tiger Lite

First public Lite release.

- Dedicated Firefox profile with the Tiger Baseline (`user.js`).
- Native Firefox vertical tabs restyled as square Omarchy rows.
- uBlock Origin 1.75.0 and Bitwarden 2026.10.0 bundled and pinned.
- Tiger Tools: `>_` toolbar button, `Alt+Shift+T`, new-tab override.
- Tiger Theme: palette popup, `Alt+Shift+Y`, live `browser.theme.update()` and
  `omarchy theme set` integration.
- Rust native messaging host: terminal toggle, theme list/current/set.
- Right-docked `foot` + `tmux` terminal with Hyprland window rules.
- Square new-tab dashboard with Google/DuckDuckGo switch, suggestions off.
- Installer, uninstaller, AMO unlisted signing script, icon pipeline, docs.
- Threat model, privacy notes, baseline reference, troubleshooting guide.
